# Conversation-Improvement

[中文](README.zh-CN.md) | [English](README.md) | **日本語**

対話 AI 向けの、複数エージェントに対応するビジュアル表現と永続画像メモリのプロジェクトです。Hermes Agent 専用ではありません。ポリシーと画像ライブラリのコアを共有し、各エージェントにはネイティブプラグインアダプターを用意します。

## 機能

- 新しい画像を明示的に生成、またはアーカイブ済み画像を取得します。
- 作成日時、意味タグ、ソース、SHA-256 ID とともにメディアを保存します。
- 自動リアクションは一致するライブラリ画像を優先して再利用し、存在しない場合のみ生成します。
- 過去画像の要求では代替画像を再生成せず、アーカイブだけを検索します。
- 深刻な会話、コーディング、学習、デバッグ、プライバシー、健康、苦痛の文脈では自動メディアを禁止します。
- 恒久的な参照画像、プリセット画像/GIF ディレクトリ、明示要求時のみの生成をサポートします。
- 自動リアクションは、ちびキャラ、1 人、見える手の動き、自然な表情、余白背景を維持します。
- API Key をプラグイン設定へ保存せず、生の生成プロンプトもデフォルトでは保存しません。

## アーキテクチャ

```text
Conversation-Improvement
├── 共有ポリシーエンジン
├── 永続画像ライブラリ
├── Provider 非依存の生成・アーカイブ操作
└── ネイティブ Agent アダプター
    ├── Hermes Agent
    ├── OpenClaw
    ├── ElizaOS
    ├── Open WebUI
    ├── Botpress
    └── その他の検証済み対話プラグインホスト
```

本プロジェクトは **MCP を主要な配布層として使用しません**。完全なビジュアル会話拡張には、ホスト固有のターン Hook、セッション状態、画像生成、メディア送信が必要です。これらはネイティブプラグインアダプターで統合します。

## アダプター契約

完全なネイティブアダプターは、ホストが提供する次の機能を可能な限り対応付けます。

1. プラグインのライフサイクルと永続設定。
2. ターン単位の Hook、イベント、または Middleware。
3. ツール登録。
4. 画像生成 Provider の呼び出し。
5. 現在の会話への画像/GIF 送信。
6. 会話ごとのクールダウンと使用回数状態。
7. 初回セットアップ UI またはコマンド。

ホストのプラグイン API に一部機能がない場合は制限付きアダプターを提供できますが、完全互換として扱わず、制限を明記します。

## Agent 互換性

| Agent / ホスト | ネイティブ拡張機構 | 状態 |
| --- | --- | --- |
| Hermes Agent | ネイティブ Python プラグイン、ツール、Hook、コマンド | **実装・テスト済み** |
| OpenClaw | ネイティブ TypeScript プラグイン、型付き会話 Hook、ツール、セッション添付送信 | **アダプター実装済み。SDK ビルドと 3 件の動作テストは合格。実 Gateway/チャネル受入試験は未実施** |
| ElizaOS | ネイティブプラグイン、イベント、Provider、Evaluator、Action、Memory、メディアコールバック | 完全適応可能、計画中 |
| Open WebUI | ネイティブ Filter、Tool、Valve、メッセージ/ファイルイベント | 完全適応可能、計画中 |
| Botpress | ネイティブ Hook、Integration、Action、スコープ状態、メディアカード | 完全適応可能、計画中 |
| Dify / LibreChat / Rasa / Flowise | ネイティブ拡張面はあるものの、共通ターン Hook、設定、または信頼できるメディア機能の少なくとも 1 つが制限される | 制限版のみ。完全自動リアクションの対象外 |
| コーディングエージェントおよび適切なネイティブプラグイン API がないホスト | 対話ネイティブプラグインの対象外 | Conversation-Improvement では非対応 |

「予定」は現在の互換性を意味しません。アダプターを実装し、対象ホストで実行確認した後にのみ対応済みと表示します。

## ネイティブアダプター

- `adapters/openclaw`：OpenClaw ネイティブ TypeScript アダプター

完全アダプターの予定：ElizaOS、Open WebUI、Botpress。

## Hermes Agent アダプター

Hermes は最初に完成したアダプターです。設定、画像生成、アーカイブ検索、自動リアクションポリシー注入、メディアアーカイブ、任意のスターターパック生成を提供します。

```bash
hermes plugins install FirmaSpring/Conversation-Improvement --enable
```

Hermes アダプターの実行データは次に保存されます。

```text
$HERMES_HOME/conversation-improvement/
```

API Key は設定に保存されません。Hermes の資格情報プール参照または環境変数名を使用できます。生成・インポートしたメディアは、ユーザーが削除するまでローカルに残ります。

## 開発

```bash
python -m pytest -q
```

新しいアダプターはポリシーとライブラリモジュールを再利用し、動作を複製しないでください。各アダプターはホスト権限、メディア送信動作、保存場所、未対応機能を記載する必要があります。
