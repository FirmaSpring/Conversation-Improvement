# Conversation-Improvement

[中文](README.zh-CN.md) | [English](README.md) | **日本語**

対話 AI 向けのビジュアル表現と永続的な画像メモリプラグインです。

## 機能

- ユーザーは新しい画像の生成、またはアーカイブ済みの古い画像の表示を明示的に要求できます。
- 画像ファイルを作成日時、意味タグ、ソース、SHA-256 ID とともに保存します。
- 自動リアクション画像は、まずライブラリ内の一致する画像を再利用し、存在しない場合だけ新規生成します。
- ユーザーが古い画像を求めた場合はアーカイブだけを検索し、置き換え画像を再生成しません。
- 自動ビジュアル表現は抑制的です。深刻な会話、コーディング、学習、デバッグ、プライバシー、健康、苦痛の文脈ではブロックされます。
- 恒久的なキャラクター参照画像、プリセット画像/GIF ディレクトリ、明示要求時のみの生成をサポートします。
- 自動リアクションには、ちびキャラ、余白背景、1 人、見える手の動き、自然な表情のスタイルを使います。

## 現在の Hermes Agent 統合

このリポジトリには、設定、生成、アーカイブ検索、任意のスターターパック生成を提供する Hermes Agent ネイティブプラグインが含まれます。

```bash
hermes plugins install FirmaSpring/Conversation-Improvement --enable
```

## 重要なプライバシー動作

- 実行時データは `$HERMES_HOME/conversation-improvement/` に保存されます。
- API Key はプラグイン設定に保存されません。Hermes の資格情報プール参照または環境変数名を使用できます。
- 生の画像生成プロンプトはデフォルトでアーカイブされません。
- 生成またはインポートしたメディアは、ユーザーが削除するまでローカルライブラリに残ります。

## 複数 Agent への対応方針

ポリシーエンジンとローカル画像ライブラリ形式は複数の Agent で共有できます。ただし完全な統合には、各ホストが次の 3 つを提供する必要があります。

1. 画像生成プロバイダーまたはツール。
2. ユーザーへ画像/GIF を送信する仕組み。
3. ポリシー判断を行う会話単位の Hook または Middleware。

| 接続方法 | 状態 | 備考 |
| --- | --- | --- |
| Hermes Agent ネイティブプラグイン | 利用可能 | このリポジトリに含まれます。 |
| 共有ポリシー/ライブラリコア | 計画中 | フレームワーク非依存の Python パッケージにします。 |
| MCP | 調査が必要 | MCP はアーカイブ、検索、生成操作を公開できますが、ホスト側の自動メッセージ Hook やメディア送信を単独では保証できません。 |
| OpenClaw / Claude Code / Codex / OpenCode / Cursor / VS Code / Cline / Continue | アダプター調査が必要 | 各ホストでテストするまで互換性を主張しません。 |
